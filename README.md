Smart Irrigation and Animal Detection System GitHub Repository README — Project Documentation Arduino Uno–based agricultural automation project Project Overview An Arduino Uno–based agricultural automation project that combines automatic soil-moisture-based irrigation with night-time animal/movement detection. The system continuously monitors soil moisture and automatically controls a water pump. During night mode, a PIR sensor detects movement and provides a local warning through an LED, buzzer, and 16×2 LCD. Project Type: Academic / Embedded Systems / Smart Agriculture Controller: Arduino Uno R3 Applications: Smart Farming, Irrigation Automation, Field Monitoring Objectives • Monitor soil moisture continuously. • Automatically control the irrigation pump according to soil conditions. • Detect movement in the agricultural field using a PIR sensor. • Enable animal detection primarily during night mode. • Provide immediate alerts using an LED and buzzer. • Display moisture and system status on a 16×2 LCD. • Reduce unnecessary water usage through condition-based irrigation. • Demonstrate an affordable and expandable smart-agriculture prototype. Why Is This Project Needed? 1. Inefficient Irrigation: Manual irrigation requires regular supervision, while fixed-time irrigation cannot respond to the actual moisture condition of the soil. This system measures soil moisture and automatically operates the pump according to a programmed threshold. 2. Night-Time Movement Detection: Movement in agricultural fields can go unnoticed at night. The PIR sensor provides a simple local warning when movement is detected during night mode. Project Purpose This project demonstrates how an Arduino Uno can combine sensors, decision-making, and actuators to solve practical agricultural problems. It is designed primarily as an educational and prototype smart-farming project and provides a foundation for future agricultural monitoring and automation.
