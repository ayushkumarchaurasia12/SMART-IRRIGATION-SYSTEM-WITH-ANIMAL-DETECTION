SMART IRRIGATION AND ANIMAL DETECTION SYSTEM Arduino Uno Based Agriculture Monitoring and Automation Project.

Agriculture depends on timely irrigation and protection of crops from environmental and biological threats. This project combines two useful functions in one Arduino-based system: smart irrigation and animal detection. A soil moisture sensor measures the moisture condition of the soil. When the measured value falls below a programmed threshold, the Arduino switches the DC pump ON. When sufficient moisture is present, the pump is switched OFF. A day/night input determines whether the animal-detection function is active. At night, a PIR sensor detects movement and the system activates an LED and buzzer while displaying an alert on the LCD. The design demonstrates how low-cost embedded electronics can automate routine agricultural tasks, reduce unnecessary water use, and provide an early warning when movement is detected in a field. The system is intended as a prototype and can be expanded with wireless communication, additional sensors, solar power, and data logging. Keywords: Arduino Uno, smart irrigation, soil moisture, PIR sensor, animal detection, agriculture, DC pump, LCD, automation.
